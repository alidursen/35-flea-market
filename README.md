# README

This a repository to collect and share my various musings on D&D3.5. As we're talking about a game reaching 25 years at this point, I ask you to drop any expectations of professionalism. This includes

* not following official formatting,
* limited graphics/layout,
* no playtesting,
* continuous development,
* possibly long breaks
* and so on.

In other words, this is a hobby project of a gamer who loves 3.5 and molding that clay into a shape they like.

In return, I drop any expectation of payment from readers. If you find yourself reaching for your wallet,
may I interest you in our [professional (and paid) works](https://daelightstudios.itch.io/)?

Only the files and folders designated as `[GFM]` are part of the Flea Market and shared through Open Gaming License.
